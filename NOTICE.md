# Conteúdo desta publicação

Esta publicação contém o código Python do servidor experimental, documentação,
metadados de compatibilidade e amostras técnicas do protocolo para regressão.
A licença MIT é aplicada ao código e à documentação deste repositório.

Não são distribuídos o instalador, executáveis, bibliotecas, modelos, texturas,
animações, músicas, vídeos ou arquivos XPK do cliente KickOff. O cliente original
e suas marcas não são relicenciados por este repositório. Para testes gráficos,
o participante deve fornecer sua própria instalação compatível.

Os recursos JSON descrevem IDs, valores de catálogo, perfis de criação e
recompensas necessários ao servidor. Não contêm artes nem os scripts completos
do jogo. Os fixtures são exemplos pequenos de mensagens do ambiente de teste;
não são dumps completos de tráfego ou senhas de contas reais.

O Campo do Morro, as traduções e as mudanças visuais do ambiente de pesquisa
não fazem parte deste pacote de servidor.
